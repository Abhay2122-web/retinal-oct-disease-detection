# Retinal Disease Detection Using Deep Learning on OCT Images

This project classifies retinal Optical Coherence Tomography (OCT) images into four dataset categories: **CNV, DME, DRUSEN and NORMAL**.

## Project files

| File/folder | Purpose |
|---|---|
| `app.py` | Streamlit app: dataset explorer, image upload, prediction, confidence and Grad-CAM |
| `data_utils.py` | Hugging Face dataset loading, preprocessing, augmentation and PyTorch Dataset |
| `models.py` | Custom CNN, ResNet18, VGG16, MobileNetV2 and DenseNet121 |
| `train.py` | Training, validation, early stopping, test metrics and confusion matrix |
| `gradcam.py` | Grad-CAM heatmap generation |
| `compare_models.py` | Sequentially trains all five architectures |
| `oct_dataset.py` | Dataset exploration and sample image visualization |
| `config.py` | Shared settings |
| `requirements.txt` | Python dependencies |
| `models/` | Created automatically; stores trained checkpoints |
| `outputs/` | Created automatically; stores metrics and confusion matrices |

## Setup on Windows PowerShell

Open the project folder in VS Code, then run:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

The OCT2017 dataset is downloaded/cached from Hugging Face when first used. An internet connection is required. Pretrained torchvision weights may also download on first training.

## Step 1 — inspect the dataset

```powershell
python oct_dataset.py
```

## Step 2 — train one model

For a practical first run, start with ResNet18:

```powershell
python train.py --model resnet18 --epochs 5 --batch-size 32
```

For a quick code test using only 1,000 training examples:

```powershell
python train.py --model resnet18 --epochs 1 --max-train-samples 1000 --batch-size 16
```

`--max-train-samples 0` (the default) uses the full training split. The quick-test option is only for checking that the pipeline runs; do not present its metrics as final project results.

Optional examples:

```powershell
python train.py --model custom_cnn --epochs 10
python train.py --model mobilenet_v2 --epochs 5 --freeze-backbone
python train.py --model densenet121 --epochs 5
python train.py --model vgg16 --epochs 5
```

Training all images and all epochs can take a long time, especially on CPU. Use a CUDA-enabled PyTorch installation and a suitable GPU if available.

## Step 3 — compare architectures

```powershell
python compare_models.py
```

This runs custom CNN, ResNet18, VGG16, MobileNetV2 and DenseNet121 sequentially. It can take many hours on CPU. Run models individually if you need to manage time or memory.

## Step 4 — start the Streamlit application

```powershell
streamlit run app.py
```

Open the local URL shown in the terminal. Choose a saved checkpoint, upload a JPG/PNG/BMP OCT image, and click **Classify image**. The app displays the predicted dataset category, model confidence, class probabilities and Grad-CAM heatmap.

## Evaluation outputs

After training, check:
- `models/<model>_best.pth` — best checkpoint selected using validation loss
- `outputs/<model>_metrics.json` — test accuracy, weighted precision, recall, F1 and class-wise report
- `outputs/<model>_confusion_matrix.png` — test confusion matrix

The test split is kept separate from the training/validation split. The validation subset is selected from the training split.

## Methodology

1. Load OCT2017 from Hugging Face.
2. Inspect class labels and image samples.
3. Convert to three-channel grayscale, resize, tensor conversion and ImageNet normalization.
4. Apply training-only horizontal flip and small rotation augmentation.
5. Train CNN architectures with cross-entropy loss and AdamW.
6. Monitor validation loss and apply learning-rate reduction and early stopping.
7. Evaluate on the separate test split with accuracy, precision, recall, F1 and confusion matrix.
8. Use Grad-CAM to visualize image regions influencing a model prediction.
9. Provide a Streamlit upload and prediction interface.

## Important limitations and responsible use

- This is an educational project, not a clinically validated medical device.
- Predictions must not be used for diagnosis, treatment, or patient-care decisions.
- Confidence scores are model probabilities, not calibrated medical certainty.
- Grad-CAM is an approximate model-explanation visualization and does not prove that the model uses clinically valid features.
- Report the actual metrics generated by your run. Do not invent accuracy figures.
- Dataset access, downloads, GPU/CPU speed and memory determine how long training takes.
